Features

Everything SSH in one window

No more switching between apps, hunting for passwords in text files, or re-typing SSH commands from memory.

Encrypted Vault

AES-256-GCM with Argon2id key derivation. Your master password never leaves the device. Every write re-verifies the password before overwriting.

Embedded Terminals

Full PTY sessions via ConPTY. Tabbed for sequential work, Grid mode for parallel sessions — drag and resize each pane freely. Password auto-typed on prompt.

Dual-Pane SFTP

Browse local and remote filesystems side by side. Upload and download with auto-authentication. Navigates to /home/{user} on connect.

Command Palette

Ctrl+K launches a fast overlay. Search by hostname, label, user, or group. Arrow-key navigation with Ctrl+Enter for SSH and Ctrl+Shift+Enter for SFTP.

One-Click Backup

Bundle vault + all SSH keys into a single encrypted .tmb file. Native save dialogs — you choose the path. Restore recovers both hosts and key files atomically.

Grid View

Ctrl+G switches all active terminals into a draggable, resizable grid. Tile 2, 4, or 6 servers side by side. Exit grid to return to tabbed focus.

Security

Vault format — transparent by design

The on-disk format is deterministic and auditable. No proprietary binary blobs.

6 bytesMKTRV1
16 bytesSalt
12 bytesNonce
variableAES-256-GCM( JSON(hosts[]) )
Encryption
AES-256-GCM — authenticated encryption. Any bit flip invalidates the auth tag before decryption.
Key Derivation
Argon2id default params. Password is never stored; derived key lives only in RAM during the session.
Write Safety
Every save decrypts first — wrong password can't overwrite your vault with garbage data.
